Importing your quiz .zip into Canvas

The builder gives you a .zip file in the QTI format. Canvas can read it directly, so do not unzip it; upload the .zip itself.

Safari users: Safari may unzip downloads automatically, leaving a folder instead of a .zip. If that happens, turn off Safari → Settings → General → “Open ‘safe’ files after downloading” and download again (or use the .zip from your Trash).

  2. Put the questions in an item bank (recommended)
  3. Use the item bank in a quiz

1. Turn on New Quizzes (if needed)

Item banks belong to Canvas New Quizzes. Many courses have it on already. If you don’t see New Quizzes or Item Banks:

  1. In your course, open Settings (bottom of the course menu).
  2. Open the Feature Options tab (some versions call it Features).
  3. Find New Quizzes and switch it on.

If the switch is missing or locked, your Canvas administrator controls it. Contact your school’s Canvas support.

2. Put the questions in an item bank (recommended)

An item bank is a reusable collection of questions. Importing into a bank lets you build several quizzes (or randomized versions of one quiz) from the same questions.

  1. Open Item Banks. Depending on your Canvas version, it is either a link in the course menu, or inside any New Quiz under Build → the item bank icon in the right-hand toolbar.
  2. Create a new item bank and give it a name, for example the quiz title.
  3. Check the box to share the bank with the course so it’s available in this class (and to co-teachers).
  4. On the new bank, open the ⋯ (more options) menu and choose Import Content.
  5. Choose the .zip you downloaded from this site and confirm the import.
  6. Wait for the import to finish. Large quizzes can take a minute. Then open the bank to see your questions.

3. Use the item bank in a quiz

  1. Go to Quizzes and create a quiz, choosing New Quizzes if asked.
  2. On the quiz’s Build page, press the + button and choose Item Bank.
  3. Pick your bank. You can add specific questions, or add the whole bank and have Canvas pick a random number of questions for each student.
  4. Set points, time limits and due dates as usual, then Publish.

4. Alternative: import as a whole quiz

If you just want one ready-made quiz, without a bank:

  1. Open the course Settings and choose Import Course Content.
  2. For Content Type, choose QTI .zip file.
  3. Choose your .zip. If you see Import existing quizzes as New Quizzes, check it.
  4. Press Import and wait until the job shows Completed.
  5. The quiz appears under Quizzes, unpublished, with the title from your Quiz title: line.

5. Check your questions

  • Preview the quiz (or use Student View) before publishing to check wording, answers and math.
  • Each question is worth 1 point unless you set Points: 2 (etc.) in your quiz text.
  • Short-answer questions only accept the exact answers you listed with *, so list common spellings.
  • To fix a mistake, edit the text in the builder, download a new .zip and import it again, or edit the question directly in Canvas.

Canvas changes its menus from time to time, so some labels may be slightly different in your course. For the official instructions, search the Canvas Instructor Guide for “import QTI” or “item banks”.
